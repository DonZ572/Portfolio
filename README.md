# Portfolio — Donatien Zinsou

Portfolio personnel : cybersécurité & communication digitale.
À la recherche d'une **alternance de 33 mois à partir de septembre 2026** (Pré-Master Cybersécurité, Epitech).

## Contenu

- **Accueil** : présentation, objectif d'alternance, contact rapide
- **Réalisations** : GestizApp et Postuly (en ligne), et trois projets web académiques détaillés sur leur propre page
- **Parcours** : expériences professionnelles et associatives
- **Savoir-faire** : développement web, sécurité, données & cloud, gestion de projet
- **Formation**, **centres d'intérêt** et **formulaire de contact**

## Technologies

- **HTML, CSS et JavaScript natifs** : aucun framework, aucune bibliothèque, rien à installer
- Polices Google Fonts (Anton, Space Grotesk, Space Mono)
- Hébergement : GitHub Pages

## Fonctionnalités

- Design responsive (ordinateur, tablette, mobile)
- Terminal de commandes : appuyez sur `/` puis tapez `projets`, `contact`, `cv`, `nb`, `negatif`…
- Menu plein écran, animations au défilement, respect du réglage « réduire les animations »
- Formulaire de contact envoyé via l'API REST d'EmailJS (appel `fetch`, sans bibliothèque), avec protection anti-robots

## Structure

```

projects/ecole.html       projet Site de l'école
assets/Css/studio.css     feuille de style

```

## Lancer en local

Ouvrir `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Mise en ligne (GitHub Pages)

1. Dépôt **public** sur GitHub contenant ces fichiers à la racine
2. **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**
3. Le site est disponible après quelques minutes à l'adresse `https://<utilisateur>.github.io/<dépôt>/`
