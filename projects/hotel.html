Projet 02 / 03 · Template web · PHP

Réservation Hôtel

Application web de gestion hôtelière permettant l'administration des chambres, la gestion des réservations et le suivi des clients via une interface dédiée.

  • PHP
  • MySQL
(01)

Contexte

Ce projet repose sur l'utilisation et l'analyse d'un template de système de réservation hôtelière, réalisé dans le cadre de ma formation en développement web.

L'objectif principal était de comprendre le fonctionnement global d'une application métier existante, notamment la logique de réservation, la gestion des chambres et l'organisation d'une base de données relationnelle.

Ce travail m'a permis de renforcer mes compétences en lecture de code PHP, en analyse back-end et en compréhension des systèmes de gestion hôtelière.

(02)

Fonctionnalités étudiées

  • 01

    Interface administrateur

    Analyse du tableau de bord permettant la gestion des chambres et des réservations clients.

  • 02

    Gestion des chambres

    Compréhension du système de création, modification et suppression des chambres avec leurs caractéristiques.

  • 03

    Système de réservation

    Étude du fonctionnement des réservations selon les dates, disponibilités et contraintes.

  • 04

    Base de données relationnelle

    Analyse des relations entre clients, chambres et réservations.

(03)

Technique

Template existant basé sur PHP
Base de données MySQL relationnelle
Analyse de la logique métier côté serveur
Tests fonctionnels et compréhension du flux applicatif

Compétences développées

  • Lecture de code PHP
  • Analyse de template
  • MySQL
  • Systèmes de réservation
